## Sobre / About

Um catálogo abrangente de extensões de arquivos organizadas por categoria.

A comprehensive catalog of file extensions organized by category.

⚠️ Uma extensão não identifica com segurança o conteúdo real de um arquivo.  
⚠️ An extension does not securely identify a file's actual contents.

## Contribuição / Contributing

Contribuições são bem-vindas:

1. Faça um fork do repositório.
2. Adicione a extensão em uma categoria adequada.
3. Informe descrição em PT e EN.
4. Adicione tipo MIME e padrão/licença quando conhecidos.
5. Inclua fontes oficiais sempre que possível.
6. Envie um Pull Request.

Contributions are welcome:

1. Fork the repository.
2. Add the extension to an appropriate category.
3. Include descriptions in PT and EN.
4. Add MIME type and license/open-standard information.
5. Include official sources whenever possible.
6. Submit a Pull Request.

## Aviso / Disclaimer

Este catálogo é informativo. Extensões podem ser reutilizadas por diferentes formatos e não devem ser consideradas prova de segurança ou autenticidade. Este projeto não serve como verificação digital forense.

This catalog is informational. Extensions may be reused by different formats and do not prove file safety or authenticity. This project is not a forensic file-identification system.
